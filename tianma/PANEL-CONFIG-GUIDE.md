# 天马 / 快马面板配置指南

适用于 Horse-UI `1.0.0-skyhorse-rc30`。  
覆盖天马（SkyHorse）第四代、快马（FastHorse）第二代的全部面板配置项、填写范围、推荐值和完整配置流程。

> 范围说明  
> “有效范围”是代码/内核实际能接受的范围；“推荐值”是稳定优先的实践值，不是硬性要求。  
> 面板中标记为无效的字段不要开启，下面会单独说明。

---

## 一、配置前准备

### 1.1 先准备证书

天马和快马都强制 TLS，必须先有证书。

面板路径：

```
证书管理 → 新建证书
```

两种来源：

| 来源 | 适用 | 说明 |
|---|---|---|
| 自签证书 | 没有域名、没有 CA | 客户端必须开启“跳过证书校验”或固定指纹 |
| ACME 证书 | 有域名 | 自动续签，客户端可正常校验 |

自签证书建议：

```
密钥类型：EC P-256
有效期：365 天
SAN：服务器 IP、127.0.0.1、localhost
```

### 1.2 确认端口

```
面板：8080（不要和节点冲突）
天马：UDP 10000 起
快马：TCP 20000 起
```

端口必须避开：

```
22、80、443、8080
已存在的入站端口
系统服务端口
```

### 1.3 确认面板版本

```
设置 → 关于 → 版本
```

当前版本：`1.0.0-skyhorse-rc30`。

## 二、天马（SkyHorse）入站配置

### 2.1 基础项

路径：

```
入站 → 新增入站 → 协议类型 SkyHorse
```

| 面板项 | 作用 | 有效范围 | 推荐值 | 说明 |
|---|---|---|---|---|
| 协议类型 | 选择 SkyHorse | 固定 | SkyHorse | 不要选错 |
| 标识 tag | 入站唯一名 | 1–64 字符 | `skyhorse-10000` | 留空自动生成 |
| 监听地址 | 绑定的本机地址 | `::` / `0.0.0.0` / 具体 IP | `::` | `::` 同时监听 IPv4/IPv6 |
| 端口 | 主监听端口 | 1–65535 | `10000` | UDP |
| 备注 | 备注 | 任意 | 可空 | 不影响运行 |
| 启用 | 是否启用 | 开/关 | 开 | 关闭后不监听 |
| 嗅探 | 目标域名嗅探 | 开/关 | 开 | 用于分流/日志 |
| TCP Fast Open | TCP 快速打开 | 开/关 | 关 | 天马走 UDP，此项基本无效 |
| 批量创建 | 一次建多个 | 2–100 个 | 关 | 端口步长 1–1000 |

注意：

```
天马是 UDP 协议
监听地址选 :: 时，内核会同时接受 IPv4/IPv6
```

### 2.2 天马协议项

| 面板项 | 作用 | 有效范围 | 推荐值 | 说明 |
|---|---|---|---|---|
| 上行 Mbps | 服务端接收方向带宽 | 0–100000 | 0（BBR）或真实上行 | 仅 Brutal 使用 |
| 下行 Mbps | 服务端发送方向带宽 | 0–100000 | 0（BBR）或真实下行 | 仅 Brutal 使用 |
| 门控密码 | 天马混淆/门控密码 | 8–64 字符 | 16–32 位随机 | 客户端必须一致 |
| 端口段 | 额外监听端口 | `start:end`，最多 256 个 | `10000:10009` | 留空只用主端口 |
| 节点 ID | 节点标识 | 1–32 字符 | `hk-01` | 客户端必须一致 |
| 失败行为 | 未认证连接处理 | drop / reset / close | drop | drop 最隐蔽 |
| 混淆轮换（秒） | 混淆密钥轮换 | 0–86400 | 300 | 0 表示不轮换 |
| 轮换容忍（秒） | 旧密钥容忍窗口 | 0–86400 | 60 | 要小于轮换周期 |
| 最大连接数 | 同时 QUIC 连接上限 | 1–65535 | 16–64 | 0 在内核表示不限，但面板最小 1 |
| 单连接流上限 | 每条 QUIC 并发流 | 1–1024 | 32–128 | 客户端也受限 |
| 端口轮换间隔（秒） | 客户端换端口周期 | 0–86400 | 120 | 仅开启端口跳跃时生效 |
| 启用端口跳跃 | 客户端轮换端口 | 开/关 | 关 | UDP 被 QoS 时再开 |
| 旧门控密钥 | 轮换期间的旧密码 | 每行一个 | 可空 | 用于平滑轮换 |

注意：

```
面板里“上行 Mbps / 下行 Mbps”出现两次
它们是同一个字段，填一次即可，两边会同步
```

### 2.3 访问策略

| 面板项 | 作用 | 有效范围 | 推荐值 | 说明 |
|---|---|---|---|---|
| 允许访问私网 | 允许目标为内网 | 开/关 | 关 | 防止打内网 |
| 允许访问回环 | 允许目标为 127.0.0.1 | 开/关 | 关 | 防止打本机服务 |
| 允许端口 | 目标端口白名单 | `80,443,8000-8100` | 留空 | 留空表示全部 |
| 拒绝网段 | 目标 CIDR 黑名单 | 每行一个 CIDR | 可空 | 优先于允许 |
| 允许网段 | 目标 CIDR 白名单 | 每行一个 CIDR | 留空 | 留空表示全部 |

建议：

```
不允许私网
不允许回环
端口留空
```

### 2.4 Guard 防护

| 面板项 | 作用 | 有效范围 | 推荐值 | 说明 |
|---|---|---|---|---|
| 每 IP 最大连接数 | 单 IP 并发连接 | 0–65535 | 8 | 0 表示不限 |
| 认证失败上限 | 窗口内失败次数 | 0–1000 | 8 | 0 表示关闭 |
| 失败窗口（秒） | 统计窗口 | 0–86400 | 60 | |
| 封禁（秒） | 封禁时长 | 0–86400 | 300 | |

建议：

```
每 IP 8 个连接
60 秒内失败 8 次
封 300 秒
```

### 2.5 拥塞控制

| 面板项 | 作用 | 可选值 | 推荐值 | 说明 |
|---|---|---|---|---|
| 拥塞控制 | 选择算法 | Brutal / standard / conservative / aggressive | standard | BBR 默认 |
| 禁用丢包补偿 | 关闭 Brutal 丢包补偿 | 开/关 | 关 | 仅 Brutal 有意义 |
| 忽略客户端带宽 | 服务端忽略客户端带宽 | 开/关 | 关 | 无效字段，见 2.6 |

选择规则：

```
线路正常、追求稳定：standard
线路差、想更激进：aggressive
线路极差、宁可慢：conservative
明确知道真实带宽、要丢包不降速：Brutal
```

Brutal 配置：

```
下行 Mbps = VPS 真实下行
上行 Mbps = VPS 真实上行
拥塞控制 = Brutal
```

填错后果：

```
填高：抢带宽、丢包更严重
填低：主动限速
```

### 2.6 “忽略客户端带宽”不要开

面板项：

```
忽略客户端带宽
```

当前状态：

```
字段会写入入站 extra
但订阅已不再下发到客户端
客户端内核也不识别
```

结论：

```
无效字段，不要开启
保持关闭
```

开启后不会提升速度，旧客户端还可能报：

```
unknown field "ignore_client_bandwidth"
```

### 2.7 天马 TLS

天马强制 TLS，TLS 页签必须配置。

| 面板项 | 作用 | 有效范围 | 推荐值 | 说明 |
|---|---|---|---|---|
| 启用 TLS | 强制开启 | 固定开 | 开 | 不可关 |
| 服务名 SNI | TLS SNI | 域名或 IP | 服务器 IP/域名 | 自签可填 IP |
| ALPN | 应用层协议 | `h3` | `h3` | 天马使用 h3 |
| 最低版本 | TLS 最低版本 | TLS 1.2/1.3 | TLS 1.3 | |
| 最高版本 | TLS 最高版本 | TLS 1.3 | TLS 1.3 | |
| 加密套件 | 自定义套件 | 多选 | 留空 | 默认即可 |
| 证书来源 | 手动/面板 | 二选一 | 面板证书 | |
| 选择证书 | 面板证书 | 列表 | 自签或 ACME | |
| 客户端跳验证 | 下发 insecure | 开/关 | 自签必须开 | ACME 可关 |
| 客户端认证 | mTLS | 无/请求/要求 | 无 | 一般不用 |
| CA 证书路径 | 校验客户端 CA | 文件路径 | 空 | mTLS 才填 |
| 证书公钥 SHA256 | 客户端证书指纹 | 64 位十六进制 | 空 | 可选 |

自签证书：

```
客户端跳验证 = 开
```

否则客户端报：

```
x509: certificate signed by unknown authority
```

## 三、快马（FastHorse）入站配置

### 3.1 基础项

与天马相同：

| 面板项 | 推荐值 |
|---|---|
| 协议类型 | FastHorse |
| 标识 | `fasthorse-20000` |
| 监听地址 | `::` |
| 端口 | `20000`（TCP） |
| 启用 | 开 |
| 嗅探 | 开 |
| TCP Fast Open | 可开（TCP 有效） |

### 3.2 快马协议项

| 面板项 | 作用 | 有效范围 | 推荐值 | 说明 |
|---|---|---|---|---|
| 混淆密码 | obfs 密码 | 8–64 字符 | 16–32 位随机 | 必填，客户端一致 |
| 端口段 | 额外监听端口 | `start:end`，最多 256 个 | `20000:20009` | 留空只用主端口 |
| 启用端口跳跃 | 客户端换端口 | 开/关 | 关 | 默认关闭 |
| 端口轮换（秒） | 换端口周期 | 0–86400 | 120 | 仅开启跳跃时生效 |
| 单连接流上限 | H2 并发流 | 1–1024 | 64 | 服务端 MaxConcurrentStreams |
| 上行 Mbps | 客户端上行限速 | 0–100000 | 真实上行 | 0 表示不限 |
| 下行 Mbps | 服务端下行限速 | 0–100000 | 真实下行 | 0 表示不限 |
| 轮换（秒） | obfs 密钥轮换 | 0–86400 | 3600 | |
| 容忍（秒） | 旧密钥容忍 | 0–86400 | 3600 | |
| 填充到（字节） | 握手包填充 | -1–65535 | 1024 | -1 关闭 |
| 节点 ID | 门控节点标识 | 1–32 字符 | `hk-01` | 客户端一致 |
| 失败行为 | 未认证处理 | drop / reset / close | drop | |
| 失败延迟（毫秒） | 失败前延迟 | 0–10000 | 1500 | 增加探测成本 |
| 旧密钥版本 | 轮换旧密钥 | ID 0–255 + 密码 | 可空 | 过渡用 |

注意：

```
快马是 TCP
单连接多流
一条连接断，所有流一起断
```

### 3.3 快马 TLS

| 面板项 | 推荐值 | 说明 |
|---|---|---|
| 服务名 SNI | 服务器 IP/域名 | 自签可填 IP |
| ALPN | `h2` | 快马使用 H2 |
| 最低版本 | TLS 1.3 | |
| 证书 | 面板自签/ACME | |
| 客户端跳验证 | 自签开，ACME 关 | |

### 3.4 快马限速填写

```
上行 Mbps = 客户端到服务端方向
下行 Mbps = 服务端到客户端方向
```

建议：

```
按 VPS 真实带宽填
不要填 0 以外的虚假值
0 表示不限
```

## 四、创建用户

### 4.1 天马用户

路径：

```
用户 → 新增用户 → 所属入站选天马
```

需要：

```
用户名
UUID
密码
```

建议：

```
UUID：自动生成
密码：16–32 位随机
```

天马认证：

```
UUID + 密码
TLS exporter token 绑定连接
```

### 4.2 快马用户

需要：

```
用户名
密码
```

建议：

```
用户名：英文/数字
密码：16–32 位随机
```

快马认证：

```
username + password
```

### 4.3 一个用户绑多个入站

只建议绑定凭据兼容的协议。

天马 + 快马可以：

```
天马需要 UUID + 密码
快马需要用户名 + 密码
同一用户三者都有
```

天马 + VLESS 不行：

```
VLESS 不需要密码
快马/天马需要密码
```

## 五、订阅与客户端

### 5.1 生成订阅

路径：

```
用户 → 订阅 → 复制链接
```

链接格式：

```
https://面板地址:8080/sub/<token>?target=singbox
```

注意：

```
客户端必须用新 token
旧 token 在重装/重建后失效
```

### 5.2 客户端导入

HorseBox：

```
订阅 → 添加
粘贴链接
拉取
```

导入后检查：

```
节点 IP 是否为当前服务器
端口是否为 10000/20000
协议是否为 skyhorse/fasthorse
```

### 5.3 自签证书

客户端需要：

```
跳过证书校验
或固定证书指纹
```

否则报：

```
unknown certificate
```

## 六、保存与应用

点击保存后：

```
面板写入数据库
生成 config.json
校验配置
重启 sing-box
```

注意：

```
应用配置会短暂断流
不要频繁保存
```

应用后检查：

```
内核状态：运行
端口监听：10000/20000
日志：无 unknown field
```

## 七、验证流程

### 7.1 服务端

```bash
ss -lunp | grep -E '10000|10010'
ss -lntp | grep 20000
ps aux | grep '[s]ing-box'
journalctl -u horseui -n 50
```

### 7.2 配置

```bash
/etc/horseui/bin/sing-box check -c /etc/horseui/config.json
```

### 7.3 面板测速

```
入站 → 天马 → 测速
```

面板测速是从服务器本机回环发起的，不经过你的客户端。

失败常见原因：

```
自签证书未开 insecure
用户 UUID/密码为空
端口未监听
内核未运行
```

### 7.4 客户端测速

```
客户端 → 选节点 → 测速
```

失败常见原因：

```
订阅还是旧 IP
端口不对
UUID/密码不一致
OBFS/门控密码不一致
TLS SNI 不匹配
```

## 八、推荐配置方案

### 8.1 正常 VPS（1 Gbps，UDP 可用）

天马：

```
端口：10000
端口段：10000:10009
端口跳跃：关
端口轮换：120
最大连接：32
单连接流：64
混淆轮换：300
轮换容忍：60
拥塞控制：standard
上行/下行：0
每 IP 连接：8
认证失败：8 / 60 秒 / 封 300 秒
```

快马：

```
端口：20000
端口段：20000:20009
端口跳跃：关
单连接流：64
上行/下行：真实带宽
轮换：3600
容忍：3600
填充：1024
失败延迟：1500
```

### 8.2 高丢包线路（UDP 可用）

天马：

```
拥塞控制：Brutal
下行 Mbps：真实下行
上行 Mbps：真实上行
禁用丢包补偿：关
端口跳跃：关
```

注意：

```
必须先确认 UDP 没被 QoS
否则 Brutal 会加重丢包
```

### 8.3 UDP 被限（只保留 TCP）

天马：

```
停用，或只保留低优先级
```

快马：

```
端口：443 或 20000
端口跳跃：可开
单连接流：64
上行/下行：真实带宽
```

### 8.4 只有 IP、没有域名

证书：

```
自签
SAN 包含服务器 IP
```

入站：

```
客户端跳验证：开
```

客户端：

```
跳过证书校验
```

## 九、常见错误与处理

### 9.1 unknown field

```
outbounds[0].ignore_client_bandwidth: unknown field
```

原因：

```
旧订阅把服务端字段下发给客户端
```

处理：

```
关闭“忽略客户端带宽”
客户端重新拉订阅
```

不要开启该字段；开启后不会提升速度，旧客户端还可能报：

```
unknown field "ignore_client_bandwidth"
```

### 9.2 面板测速失败

```
测速失败：...
```

处理：

```
确认用户存在
确认端口监听
自签证书开 insecure
```

### 9.3 客户端全部超时

```
节点 IP 不对
端口不对
UDP 被 QoS
服务器未运行
```

先查：

```
ss -lunp
nstat
订阅里的 server
```

### 9.4 一个用户绑多个协议失败

原因：

```
凭据字段不兼容
```

处理：

```
只绑 UUID+密码 或 用户名+密码 兼容的组合
```

### 9.5 应用配置后断流

正常：

```
sing-box 重启
```

不要：

```
连续保存
反复重启
```

## 十一、结论

天马和快马的面板配置，核心只有三件事：

```
凭据一致
端口一致
TLS 一致
```

其余参数都是性能和防护调优。

默认建议：

```
天马：standard、端口跳跃关、流上限 64
快马：单连接流 64、上下行真实带宽、端口跳跃关
```

不要开启：

```
忽略客户端带宽
```

它是无效下发字段，已被移除。
